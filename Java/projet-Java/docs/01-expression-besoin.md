l'application cherche à résoudre la mauvaise organisation des stages.
Projet
## Sujet : 
    gestionnaire de stage

## Phrase exprimant les besoins : 
    Organiser son stage et concerver tout ce que l'on a pu effectuer.

## Les utilisateurs : 
    Moi

## Les fonctionnalités : 
    Affiche les stages les entreprises les tuteurs et le stagiaire avec toutes leurs informations.
    l'utilisateur doit pouvoir avoir toutes les informations liées à ses stages, 
    il doit pouvoir ajouter des tuteurs,
    il doit pouvoir supprimer les structures d'acceuil,
    il doit pouvoir rechercher un stage effectué,
    il doit pouvoir modifier des informations si nécessaire,
    il doit pouvoir afficher les informations de son tuteur,
    il doit pouvoir afficher les informations de la structure d'acceuil.

## MVP : 
    [ ] afficher les données,
    [ ] ajouter des données,
    [ ] supprimer des données,
    [ ] modifier des données,
    [ ] rechercher des données.

## Bonus :  
    [ ] ajouter et afficher les missions effectués,
    [ ] dashboard intéractifs,
    [ ] ajouter et afficher les compétences acquises.

## Idée data : 
    une table Stage relié aux tables organisation, tuteur, stagiaire.

## Techno utilisé : 
    Vue pour le front-end et Springboot pour le back-end postgre en cli pour la création et la gestion de la base de donnée.
